操作规则
1. 首页：头像进入账号；视频输入支持 BV、URL、完整分享文字，粘贴后提取目标并显示精简预览。清空按钮只在非空时出现；粘贴按钮可用；用户输入及失败时的草稿保留。播放、创建房间保留短文字。加入房间为独立入口，点击打开底部面板。
2. 创建房间可以由已解析的视频发起；未选片时仍允许空房。面板使用真实阶段和已用时间，不伪造百分比。成功仅在成员凭据、连接和房间快照确认后进入房间；失败原位显示短原因和重试，保留输入。取消遵守已有取消状态机。
3. 入房邀请输入支持整段文本；确认后才加入；只识别现有域名/协议，不增加任意服务器自动跳转。可复制、粘贴、一次清空；退出面板不会悄悄清空草稿。
4. 观影页：视频在上、聊天在下。影片标题最多两行；展开才看完整长标题。只保留一处简短同步状态；连接/加载异常就地显示短原因和重试，不展示堆栈和凭据。正常状态不铺说明段落。成员在顶部图标面板，人数保留 3/5。邀请图标直接复制链接并给短反馈。
5. 房主拥有播放、暂停、进度、倍速、换片权限；访客控制栏相同位置显示实际时间轴但不伪装成可控，首次点击可简短提示“由房主控制”。画质、全屏、聊天及必要的本机播放授权仍可操作。访客独立加载，不阻塞其他成员。
6. 清晰度保留 1080P 等短文字，底部列表显示真实可用项和当前勾选；切换保留进度和意图。倍速保留 1.0× 等文字，房主可以改变房间倍速，访客展示当前值。
7. 全屏：轻点偏右侧空白视频区域打开聊天；该手势避开可见控制按钮、进度条及拖动区域，并只在 ACTION_UP 判定单击。始终保留明确聊天图标作为替代入口。点面板外、关闭图标或系统返回均先收起聊天；关闭聊天不暂停。左侧/中部点按切换播放器控制层。双击、长按、滑动不误触聊天。
8. 新消息在右侧显示短预览（与 Windows 约定一致），包含昵称和最多两行正文，约 4 秒后消失；聊天打开时不重复预览，关闭后保留未读点。可点预览打开聊天。高频消息合并/有界排队，不能遮住字幕和播放控件；多余消息以未读数提示，不持续叠满屏幕。
9. 聊天面板横屏宽度约 30–35%，尊重 48dp 点击区域和可读性。窄屏或输入法展开时自适应加宽/调整高度，不挤出聊天输入框；返回先收键盘，再关聊天，再退出全屏。平板普通横屏采用视频与聊天并排；平板全屏仍可隐藏聊天。
10. 登录后显示头像、昵称、UID、简短登录状态；UID 可复制。扫码页支持复制二维码图片、刷新和状态；成功自动回到账号卡片。网页登录作为替代入口，成功后收起网页。账号页集中更新、外观和账号操作，首页不常驻版本及权限说明。
11. 异常仅在需要操作时显现。登录失效、网络失败、本机播放授权等分别给对应操作；错误不清空当前房间、影片或聊天。不用“已同步”代替真实播放器就绪。
12. 设计稿的例子均为占位内容；UID 与头像不是实际用户资料，二维码不可用。图中控件仍以本规范为准，后续实现需检查 360dp 手机、横屏、平板、大字号和无障碍操作。

生成复核修正：操作流程的蒙层背景必须与首页一致，删除生成器添加的历史/影片库；横屏稿须使用真实 20:9 比例，不能拉伸成超宽条。
