## 下载与运行

在下方 **Assets** 下载 `BiliCinema.exe`，双击运行。适用于 Windows x64，已包含 .NET 和下载工具；播放需要 Microsoft Edge WebView2 Runtime。

## 功能

- 扫码登录，支持复制二维码分享卡片。
- 播放电影、番剧及普通 B 站视频。
- 创建或加入双人观影房间，房主统一控制选片、选集与进度。
- 自动同步恢复的历史进度，并提供手动同步按钮。
- 全屏侧边聊天、新消息提醒与昵称记忆。
- 下载音视频、弹幕、字幕和封面，显示预计大小。

本版修复播放器控制栏布局与全屏底部弹幕输入栏残留问题。

操作说明见 [README](https://github.com/LeonZ03/BiliCinema#readme)。房主需保持程序运行，双方使用同一版本；内容权限取决于各自 B 站账号。
